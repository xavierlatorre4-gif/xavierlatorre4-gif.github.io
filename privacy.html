YT Growth readonly - Privacy Policy

Last updated: 19 October 2026. Operator: Xavier Latorre Arribas (xavilato06@gmail.com).

What the app does

YT Growth readonly is a private, personal analytics tool. It is used only by its owner to read performance data of the owner's own YouTube channels and produce private growth reports (views, watch time, click-through rate, audience retention, traffic sources and search terms).

Google user data accessed

  • Scope https://www.googleapis.com/auth/yt-analytics.readonly: read-only YouTube Analytics reports for the authorized channel.
  • Scope https://www.googleapis.com/auth/youtube.readonly: read-only channel and video metadata (titles, publish dates, public statistics) for the authorized channel.

The app never uploads, edits, deletes or publishes anything, and it does not access email, contacts, files or any other Google data.

How the data is used

Data is used only to generate private reports for the channel owner. It is not used for advertising, profiling, or training AI/ML models.

Sharing

Data is not sold, rented, shared or transferred to any third party.

Storage, retention and deletion

OAuth tokens and reports are stored privately on the owner's own computers with restricted file permissions. Reports are kept only as long as needed for the owner's analysis and can be deleted at any time. Access can be revoked at any time at myaccount.google.com/permissions, after which no further data is accessed.

Google API Services User Data Policy

YT Growth readonly's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. This app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
